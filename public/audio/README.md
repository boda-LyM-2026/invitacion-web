# Audio para la invitación de boda

## Instrucciones

1. Coloca tu archivo de música en esta carpeta como `background-music.mp3`
2. Formatos recomendados: MP3 (mejor compatibilidad) o OGG
3. El archivo se reproducirá en loop automático cuando el invitado abra la invitación

## Recomendaciones de música

Para mantener la elegancia cinematográfica, se sugiere:
- **Piano/clásica suave**: Melodía de piano elegante y minimalista
- **Duración**: Idealmente 3-5 minutos (se repetirá en loop)
- **Volumen**: El componente ya tiene control de volumen, pero se recomienda
  que el archivo original tenga un volumen moderado

## Fuentes de música libre de derechos

- [Pixabay Music](https://pixabay.com/music/)
- [Free Music Archive](https://freemusicarchive.org/)
- [Incompetech](https://incompetech.com/)

## Nota técnica

El componente `AudioPlayer` está configurado para:
- Reproducir en loop automático
- Guardar el estado (play/pause) en localStorage
- Respetar la preferencia del usuario entre sesiones
- Incluir controles de play/pause y volumen
